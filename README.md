🗄️ SQL Server — Практические работы
Учебный репозиторий с заданиями и практикой по работе с базами данных в Microsoft SQL Server.
📚 О проекте
В этом репозитории собраны практические работы, выполненные в процессе изучения SQL Server. Здесь представлены задания, связанные с созданием и управлением базами данных, написанием запросов и настройкой безопасности.
🛠️ Что было изучено
Работа с данными
• Создание баз данных и таблиц
• Добавление, изменение, удаление и выборка данных
• Фильтрация и сортировка результатов
• Объединение таблиц и работа с запросами
Программирование на SQL
• Представления (Views)
• Функции и хранимые процедуры
• Транзакции и обработка ошибок через TRY...CATCH
• Работа с блокировками и взаимоблокировками (Deadlocks)
• Использование индексов и оптимизация запросов
Безопасность баз данных
• Создание логинов и пользователей
• Работа с ролями базы данных
• Настройка прав доступа
• Проверка разрешений пользователей
🎯 Цель обучения
Получить практические навыки работы с реляционными базами данных, научиться писать SQL-запросы, управлять данными, настраивать безопасность и разбираться в основных механизмах работы SQL Server.
💻 Используемые технологии
• Microsoft SQL Server
• SQL (T-SQL)
• SQL Server Management Studio (SSMS)
