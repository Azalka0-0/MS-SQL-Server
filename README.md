# 📖 О проекте #
##    В данном репозитории собраны практические задания, выполненные в процессе изучения SQL Server. В ходе обучения я изучала работу с данными, создание SQL-запросов, управление базами данных и настройку безопасности. ##
#📚 Изученные темы #
## 01. Работа с данными ##
• Создание баз данных и таблиц
• Добавление, изменение и удаление записей
• Фильтрация и сортировка данных
• Объединение таблиц
## 02. Программирование на SQL ##
• Представления (VIEW)
• Функции и хранимые процедуры
• Транзакции и обработка ошибок (TRY...CATCH)
• Блокировки и взаимоблокировки (DEADLOCK)
• Индексы и оптимизация запросов
## 03. Безопасность баз данных ##
• Создание логинов и пользователей
• Работа с ролями базы данных
• Настройка прав доступа
• Проверка разрешений пользователей
