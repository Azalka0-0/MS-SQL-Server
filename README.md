SQL Server — Учебные работы
В этом репозитории собраны практические задания по SQL Server, которые выполнялись в процессе обучения.
В ходе работы я научилась:
• Создавать базы данных и таблицы.
• Писать SQL-запросы для добавления, изменения, удаления и получения данных.
• Использовать фильтрацию, сортировку и объединение таблиц.
• Работать с представлениями, функциями и хранимыми процедурами.
• Использовать транзакции и обрабатывать ошибки с помощью TRY...CATCH.
• Разбираться в блокировках и взаимоблокировках (deadlocks).
• Работать с индексами для оптимизации запросов.
• Создавать логины, пользователей и роли.
• Настраивать права доступа и проверять разрешения пользователей.
Цель проекта: получить практические навыки работы с базами данных, научиться писать SQL-запросы, управлять доступом и понимать основные принципы работы SQL Server.
