## 1. Хранимые процедуры и функции

Хранимые процедуры позволяют объединять последовательность часто используемых SQL-запросов и сохранять её на сервере. Вместо отправки нескольких запросов достаточно отправить один запрос на выполнение процедуры. fileciteturn3file0L25-L29

### Преимущества
- повторное использование кода;
- сокращение сетевого трафика;
- безопасность;
- упрощение доступа к сложному коду;
- выполнение бизнес-логики.

## 2. Prepared Statements

Готовые инструкции позволяют создать SQL-инструкцию в виде строки и выполнить её.

Основные команды:
- `PREPARE` — создать;
- `EXECUTE` — выполнить;
- `USING` — передать переменные;
- `DEALLOCATE PREPARE` — удалить.

### PREPARE

```sql
PREPARE stmt_name FROM preparable_stmt;
```

### EXECUTE

```sql
EXECUTE stmt_name [USING @var_name [, @var_name] ...];
```

В запросе можно использовать `?`, а значение передавать через `USING`.

Пример:

```sql
SET @id = 5;

PREPARE stmt FROM
'SELECT * FROM Students WHERE id = ?';

EXECUTE stmt USING @id;
```

### Удаление

```sql
DEALLOCATE PREPARE stmt_name;
```

или:

```sql
DROP PREPARE stmt_name;
```

## 3. Хранимые процедуры

Синтаксис:

```sql
CREATE
    [DEFINER = { user | CURRENT_USER }]
    PROCEDURE имя_процедуры ([список_параметров[,...]])
    [характеристика]
    тело_процедуры
```

`DEFINER` определяет логин MySQL, используемый при проверке привилегий. По умолчанию `DEFINER=CURRENT_USER`.

Имя процедуры не может превышать 64 символа и не зависит от регистра.

---

## 4. Параметры процедур

```sql
[IN | OUT | INOUT] param_name type
```

### IN
Передаёт значение внутрь процедуры. Изменение параметра внутри процедуры снаружи не сохраняется.

### OUT
Передаёт значение из процедуры наружу. Начальное значение внутри процедуры — `NULL`.

### INOUT
Передаёт значение внутрь и позволяет вернуть изменённое значение наружу.

Если модификатор не указан, используется `IN`.

| Параметр | Назначение |
|---|---|
| `IN` | только внутрь |
| `OUT` | только наружу |
| `INOUT` | внутрь и наружу |

Для функций `OUT` и `INOUT` недопустимы — параметры функций являются входными.

## 5. Характеристики хранимого кода

```sql
LANGUAGE SQL
| [NOT] DETERMINISTIC
| { CONTAINS SQL | NO SQL | READS SQL DATA | MODIFIES SQL DATA }
| SQL SECURITY { DEFINER | INVOKER }
| COMMENT 'string'
```

### DETERMINISTIC

Показывает, зависит ли результат функции только от её аргументов.

По умолчанию:

```text
NOT DETERMINISTIC
```

### Работа с данными

- `CONTAINS SQL`
- `NO SQL`
- `READS SQL DATA`
- `MODIFIES SQL DATA`

По умолчанию — `CONTAINS SQL`.

### SQL SECURITY

```sql
SQL SECURITY DEFINER
SQL SECURITY INVOKER
```

По умолчанию — `DEFINER`.

### COMMENT

Позволяет добавить описание процедуры. Оно отображается через `SHOW CREATE PROCEDURE`.

## 6. Тело процедуры и BEGIN...END

Тело может состоять из одного запроса или составного блока.

```sql
[begin_label:] BEGIN
    statements
END [end_label]
```

Пример:

```sql
BEGIN
    DECLARE a INT DEFAULT 5;
    SELECT a;
END
```

Составные инструкции могут содержать переменные, циклы и другие конструкции управления.

Если процедура содержит только один запрос, `BEGIN...END` можно не использовать.

### DELIMITER

При создании процедур в консольном клиенте используется изменение разделителя:

```sql
DELIMITER $$

CREATE PROCEDURE someproc()
BEGIN
    SELECT 1;
END$$

DELIMITER ;
```

Вызов:

```sql
CALL someproc();
```

## 7. Переменные

В MySQL используются пользовательские переменные и переменные хранимого кода.

### Пользовательские переменные

Обозначаются через `@`:

```sql
SET @var = 123;
SELECT @var;
```

Они существуют до завершения текущего соединения.

Пример:

```sql
SET @myvar = "Hello, Aco!";
SELECT @myvar;
```

Для присваивания в выражениях предпочтительнее `:=`:

```sql
SELECT @t1:=(@t2:=1)+@t3:=4, @t1, @t2, @t3;
```

### Локальные переменные

```sql
DECLARE имя_переменной тип_данных
[DEFAULT значение_по_умолчанию];
```

Пример:

```sql
DECLARE a INT DEFAULT 5;
```

Переменные хранимого кода живут до завершения процедуры, функции или триггера, в котором они объявлены.

### Преимущества переменных
- сохранение промежуточных результатов;
- возможность использовать результат дальше;
- иногда меньшее количество сканирований таблицы;
- возможность реализовать сложную логику.

### Недостатки пользовательских переменных
- плохая переносимость на другие СУБД;
- поведение сложных запросов может зависеть от порядка выполнения, изменяемого оптимизатором.

## 8. Системные переменные

MySQL поддерживает глобальные и сеансовые переменные.

Глобальные переменные инициализируются при запуске сервера.

Изменение глобального значения:

```sql
SET GLOBAL read_buffer_size=16384;
```

Примеры системных переменных:

```text
port    — порт MySQL, по умолчанию 3306
Version — версия MySQL
```

## 9. Курсоры

Курсор — указатель на ресурс выборки.

MySQL позволяет использовать курсоры внутри хранимых процедур и функций.

Особенности:
- только чтение;
- не прокручиваются;
- не клонируются;
- могут быть очень медленными.

### Порядок объявления

1. переменные и условия;
2. курсоры;
3. обработчики.

### Создание

```sql
DECLARE cursor_name CURSOR FOR select_statement;
```

Пример:

```sql
DECLARE a, b INT;

DECLARE cur1 CURSOR FOR
SELECT value_a, value_b
FROM test.t1;
```

### Открытие

```sql
OPEN cur1;
```

### Получение строки

```sql
FETCH cur1 INTO a, b;
```

Если строк больше нет, возникает `SQLSTATE 02000`.

### Закрытие

```sql
CLOSE cur1;
```

### Полный пример

```sql
CREATE PROCEDURE curdemo()
BEGIN
    DECLARE done INT DEFAULT 0;
    DECLARE a CHAR(16);
    DECLARE b, c INT;

    DECLARE cur1 CURSOR FOR
        SELECT id, data FROM test.t1;

    DECLARE cur2 CURSOR FOR
        SELECT i FROM test.t2;

    DECLARE CONTINUE HANDLER
        FOR SQLSTATE '02000'
        SET done = 1;

    OPEN cur1;
    OPEN cur2;

    -- работа

    CLOSE cur1;
    CLOSE cur2;
END;
```

## 10. SELECT...INTO

Позволяет сохранить выбранные значения в переменные.

```sql
SELECT col_name[, ...]
INTO var_name[, ...]
table_expr;
```

Количество столбцов должно совпадать с количеством переменных.

Пример:

```sql
SELECT id, data
INTO x, y
FROM test.t1
WHERE id_tm = 5;
```

## 11. Управление потоком

В презентации рассматриваются:

- `IF...THEN...ELSE`;
- `CASE`;
- `WHILE`;
- `REPEAT`;
- `LOOP`;
- `GOTO`;
- `LEAVE`;
- `ITERATE`.

### IF

```sql
IF условие THEN
    действия
[ELSEIF условие THEN
    действия]
[ELSE
    действия]
END IF;
```

Логическое выражение принимает `0` или `1`.

### CASE

Первая форма:

```sql
CASE значение
    WHEN значение THEN действия
    [WHEN значение THEN действия]
    [ELSE действия]
END CASE;
```

Вторая форма:

```sql
CASE
    WHEN условие THEN действия
    [WHEN условие THEN действия]
    [ELSE действия]
END CASE;
```

Примеры:

```sql
SELECT CASE 1
    WHEN 1 THEN "one"
    WHEN 2 THEN "two"
    ELSE "more"
END;
```

```sql
SELECT CASE
    WHEN 1 > 0 THEN "true"
    ELSE "false"
END;
```

Если `ELSE` отсутствует и подходящего условия нет, возвращается `NULL`.

## 12. Циклы

### WHILE

```sql
[label:] WHILE условие DO
    действия
END WHILE [label];
```

Пример:

```sql
CREATE PROCEDURE NOW3()
BEGIN
    DECLARE i INT DEFAULT 3;

    WHILE i > 0 DO
        SELECT NOW();
        SET i = i - 1;
    END WHILE;
END;
```

### REPEAT

```sql
[label:] REPEAT
    действия
UNTIL условие
END REPEAT [label];
```

Цикл выполняется до тех пор, пока условие ложно.

Пример:

```sql
CREATE PROCEDURE dorepeat()
BEGIN
    DECLARE p1 INT DEFAULT 1000;
    SET @x = 0;

    REPEAT
        SET @x = @x + 1;
    UNTIL @x > p1
    END REPEAT;
END;
```

### LOOP

```sql
[label:] LOOP
    действия
END LOOP [label];
```

У `LOOP` нет собственного условия выхода, поэтому обычно используется `LEAVE`.

```sql
CREATE PROCEDURE doiterate()
BEGIN
    DECLARE p1 INT DEFAULT 5;

    label1: LOOP
        SET p1 = p1 + 1;

        IF p1 < 10 THEN
            ITERATE label1;
        END IF;

        LEAVE label1;
    END LOOP label1;

    SET @x = p1;
END;
```

### LEAVE

Досрочный выход:

```sql
LEAVE label;
```

По смыслу похож на `break`.

### ITERATE

Повторяет цикл:

```sql
ITERATE label;
```

По смыслу похож на `continue`.

### GOTO

Безусловный переход:

```sql
GOTO label;
```

## 13. Примеры процедур

### Подсчёт записей в Students

```sql
CREATE PROCEDURE numST(OUT total INT)
BEGIN
    SELECT COUNT(*)
    INTO total
    FROM Students;
END;
```

### Получение названия группы

```sql
CREATE PROCEDURE gr_nazv(
    IN kod SMALLINT,
    OUT gr_nazv CHAR(5)

BEGIN
    SELECT gruppa
    INTO gr_nazv
    FROM GRUPS
    WHERE kod_gr = kod;
END;
```

## 14. Хранимые функции

Синтаксис:

```sql
CREATE
    [DEFINER = { user | CURRENT_USER }]
    FUNCTION ([parameter[,…]])
    RETURNS type
    [characteristic…]
    routine_body
```

Функция отличается от процедуры тем, что может вызываться непосредственно и возвращает одно значение.

### Параметры

```sql
[IN] param_name type
```

`OUT` и `INOUT` для функций недопустимы.

### RETURNS

Указывает тип возвращаемого значения:

```sql
RETURNS INT
```

Функция может использовать `SELECT` для заполнения переменных, но не возвращает выборку строк как результат функции.

### Функция приветствия

```sql
CREATE FUNCTION hello(name CHAR(15))
RETURNS CHAR(50)
BEGIN
    RETURN CONCAT('Hello, ', name, '!');
END;
```

Вызов:

```sql
SELECT hello('World');
```

### Факториал

```sql
CREATE FUNCTION factorial(n INT)
RETURNS INT(11)
BEGIN
    DECLARE i INT DEFAULT 1;
    DECLARE r INT DEFAULT 1;

    WHILE i <= n DO
        SET r = r * i;
        SET i = i + 1;
    END WHILE;

    RETURN r;
END;
```

### Сравнение двух чисел

```sql
CREATE FUNCTION eq(IN a INT, IN b INT)
RETURNS TINYINT(1)
NOT DETERMINISTIC
SQL SECURITY INVOKER
COMMENT 'Пример'
BEGIN
    IF a < b THEN
        RETURN 1;
    ELSE
        RETURN 0;
    END IF;
END;
```

Вызов:

```sql
SELECT eq(1,3);
```

Результат:

```text
1
```

## 15. Процедура vs функция

| | PROCEDURE | FUNCTION |
|---|---|---|
| Создание | `CREATE PROCEDURE` | `CREATE FUNCTION` |
| Вызов | `CALL` | `SELECT function(...)` |
| Возврат | `OUT` / `INOUT` | `RETURN` |
| `IN` | Да | Да |
| `OUT` | Да | Нет |
| `INOUT` | Да | Нет |
| `RETURNS` | Нет | Да |
| Результат | Набор действий | Одно значение |

## 16. Метаданные

Список процедур:

```sql
SHOW PROCEDURE STATUS;
```

Список функций:

```sql
SHOW FUNCTION STATUS;
```

Исходный код процедуры:

```sql
SHOW CREATE PROCEDURE procedure_name;
```

Исходный код функции:

```sql
SHOW CREATE FUNCTION function_name;
```

Также можно получать информацию через:

```sql
SELECT ...
FROM mysql.proc;
```

и:

```sql
SELECT ...
FROM information_schema;
```

Информация о хранимом коде хранится в:

```text
INFORMATION_SCHEMA.ROUTINES
```

## 17. Удаление и изменение

### Удаление процедуры

```sql
DROP PROCEDURE IF EXISTS procedure_name;
```

### Удаление функции

```sql
DROP FUNCTION IF EXISTS function_name;
```

`IF EXISTS` предотвращает ошибку, если объект отсутствует.

### ALTER

```sql
ALTER {PROCEDURE | FUNCTION} sp_name
    [characteristic ...];
```

Можно менять характеристики:

```text
CONTAINS SQL
NO SQL
READS SQL DATA
MODIFIES SQL DATA
SQL SECURITY DEFINER
SQL SECURITY INVOKER
COMMENT 'string'
```

Через `ALTER` нельзя изменить аргументы или тело процедуры/функции. Для этого объект нужно удалить и создать заново.

## 18. Обработчики ошибок

Объявление:

```sql
DECLARE тип_обработчика HANDLER
FOR код_ошибки
действия;
```

### CONTINUE

После обработчика выполнение продолжается.

### EXIT

Завершает `BEGIN...END`, в котором объявлен обработчик.

### Типы условий

- `SQLSTATE` — пятисимвольный код;
- `SQLWARNING` — предупреждения;
- `NOT FOUND` — отсутствие найденных данных/объектов;
- `SQLEXCEPTION` — остальные ошибки;
- `mysql_error_code` — код ошибки MySQL;
- `condition_name` — заранее объявленное имя условия.

### DECLARE CONDITION

```sql
DECLARE condition_name CONDITION
FOR condition_value;
```

`condition_value` может быть `SQLSTATE` или кодом ошибки MySQL.
