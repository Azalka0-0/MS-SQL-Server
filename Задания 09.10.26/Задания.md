# Управление логинами, пользователями и правами доступа в SQL Server

##Задание 1. Создание SQL-логина с политикой паролей

-Создайте SQL-логин TestUser01 с паролем P@ssw0rd123!. 
-Убедитесь, что пароль соответствует политике сложности SQL Server. 
-Выполните вход под этим логином и проверьте доступ к системной базе данных master.

## Задание 2. Создание Windows-логина и сопоставление с пользователем БД

- Создать логин для учётной записи Windows `DOMAIN\JohnDoe`.
- Создать пользователя `JohnDoe` в базе данных `AdventureWorks2025` и сопоставить его с этим логином.
- Проверить, что пользователь может подключиться к базе данных.

## Задание 3. Создание пользователя без логина

- Создать пользователя `AppServiceUser` без логина (`WITHOUT LOGIN`) в базе данных `TestDB`.
- Объяснить, для чего может использоваться такой пользователь и какие ограничения он имеет.

## Задание 4. Создание логина с истёкшим сроком действия пароля

- Создать логин `TempUser` с параметрами `CHECK_EXPIRATION = ON` и `CHECK_POLICY = ON`.
- Установить пароль, срок действия которого уже истёк.
- Попробовать подключиться под этим логином и описать результат.

## Задание 5. Просмотр списка всех логинов и пользователей

- Написать запрос для вывода всех SQL-логинов на сервере.
- Отобразить дату создания каждого логина и признак его отключения (`is_disabled`).
- Написать запрос для вывода всех пользователей текущей базы данных.

## Задание 6. Добавление логина в фиксированную серверную роль

- Добавить логин `TestUser01` в серверную роль `securityadmin`.
- Проверить членство в роли.
- Описать права, которые предоставляет эта роль.

## Задание 7. Создание пользовательской серверной роли

- Создать серверную роль `CustomServerRole`.
- Предоставить ей право `ALTER ANY LOGIN`.
- Добавить логин `TestUser01` в созданную роль.
- Проверить, может ли этот логин создавать другие логины.

## Задание 8. Проверка членства в серверных ролях

- Написать запрос, который выводит все серверные роли, в которых состоит указанный логин.
- Учесть как фиксированные, так и пользовательские серверные роли.

## Задание 9. Удаление логина из роли и удаление пользовательской роли

- Удалить `TestUser01` из роли `securityadmin`.
- Удалить пользовательскую серверную роль `CustomServerRole`.
- Описать условия, которые должны быть выполнены перед удалением роли.

## Задание 10. Добавление пользователя в фиксированную роль базы данных

- Добавить пользователя `JohnDoe` в роль `db_datareader` базы данных `AdventureWorks2025`.
- Проверить, что пользователь может выполнять `SELECT` из таблиц.
- Проверить, что пользователь не может выполнять `INSERT` и `UPDATE`.

## Задание 11. Создание пользовательской роли с точечными правами

- Создать роль `SalesRole` в базе данных `AdventureWorks2025`.
- Предоставить роли права `SELECT`, `INSERT` и `UPDATE` на таблицу `Sales.SalesOrderHeader`.
- Добавить пользователя `JohnDoe` в роль `SalesRole`.

## Задание 12. Запрет (DENY) на уровне объекта

- Создать пользователя `RestrictedUser`.
- Предоставить ему право `SELECT` на всю схему `Sales` с помощью `GRANT SELECT ON SCHEMA::Sales`.
- Запретить пользователю выполнение `SELECT` на таблицу `Sales.CreditCard` с помощью `DENY`.
- Проверить, что запрет работает.

## Задание 13. Права на выполнение хранимых процедур

- Предоставить пользователю `AppServiceUser` право `EXECUTE` на хранимую процедуру `dbo.uspGetEmployeeManagers`.
- Проверить, что пользователь может выполнять указанную процедуру.
- Проверить, что пользователь не может выполнять другие процедуры без соответствующих разрешений.
